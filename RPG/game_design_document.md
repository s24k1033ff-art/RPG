# ゲーム仕様書 (GDD)

## プロジェクト概要
* **タイトル**: 『Abyss Delver: 迷宮都市の戦記』
* **ジャンル**: 見下ろし型 2Dダンジョン・ハクスラアクションRPG
* **プラットフォーム**: PC (ブラウザベース / HTML5 Canvas)
* **メインテーマ**: 『自由、挑戦、優しさ』
* **コアコンセプト**: 
  1. 拠点（都市）とダンジョンを往復する中毒性の高いゲームループ
  2. 『ソウル・ドライブ』による複数クラスの育成と、装備・素材の収集
  3. ストーリー進行が最強のビルドに直結する『記憶の欠片』システム
  4. I, O, K, L キーを用いた直感的なアクティブスキル戦闘

---

## 1. 舞台と世界観の真実
### 舞台設定と過去の真実
かつて存在した超古代の魔法文明は、無限の「虚無エネルギー」をデータ解析しコントロールしようと試みた結果、暴走を引き起こして地下へと崩落しました。それが現在の巨大迷宮「アビス」です。

**主人公の正体:**
主人公は古代文明の崩壊を食い止めるために戦った「魔導騎士（共鳴者）」です。かつての仲間たちは「自由・挑戦・優しさ」を胸に、主人公を庇って最下層で散り、主人公だけがコールドスリープ状態で現代に目覚めました。記憶を失った状態でダンジョンの浅層で倒れていたところを救助され、物語が始まります。

**黒幕（領主ヴァレリウス）:**
迷宮都市の現領主。冒険者ギルドを通じてアビスから大量の素材を集めさせていますが、真の目的は「古代の環境管理兵器」を現代に再起動させ、恐怖と力で世界を統治することです。

### 拠点の施設とゲームループ（天空の浮遊都市）
迷宮都市アビス・エッジは、奈落（アビス）の上に浮かぶ巨大な「円形の浮遊都市」です。中央の噴水広場を取り囲むように各種ギルドや工房が立ち並び、一番奥には領主邸と紫に輝く魔塔がそびえ立っています。
各施設へは広場からアクセス可能であり、右端の橋の先にあるポータルから奈落（ダンジョン）へと降下します。
* **冒険者ギルド (左上)**: クエスト受注、素材の売却換金。
* **鍛冶屋 (左下) / 宿屋 (左下)**: 武器・防具の強化や、素材を使った『自炊バフ』を行う拠点。
* **魔法道具屋 (右下) / 錬金工房 (下)**: 魔法アイテムやポーションの売買（拡張予定）。
* **領主邸 (上) / 魔塔 (右上) / 暗殺者ギルド (右下)**: ストーリーの進行に関わる重要施設。

## 2. 職業（クラス）システムの真実：『ソウル・ドライブ』
主人公が複数の職業にチェンジでき、レベルが独立している理由は、左腕に埋め込まれた古代の生体AIデバイス『ソウル・ドライブ』によるものです。
かつて共に戦い散っていった仲間たちの「魂の波長（戦闘データと記憶）」を解析し、肉体に一時的にダウンロード（憑依）させます。

### 記憶の中の仲間たち（プレイアブルクラス）
* **【剣士】アレス（初期クラス）**
  * **特徴**: 高HPと高防御力。大剣を振るう近接のスペシャリスト。
  * **過去**: 不器用だが誰よりも「優しさ」を持っていた近衛騎士。主人公を庇って致命傷を負った。
  * **成長理由**: 彼のレベルを上げることは、主人公が彼の「守り抜く」という強靭な意志と肉体に適合していく過程を表す。
* **【盗賊】シアン（第2アンロック）**
  * **特徴**: 圧倒的な移動速度と双剣による手数重視。ダッシュの無敵時間が長い。
  * **過去**: スラム出身で「自由」を何よりも愛した主人公の幼馴染。
* **【魔法使い】リリス（第3アンロック）**
  * **特徴**: 高いMPを持ち、広範囲の属性魔法を操る後衛アタッカー。
  * **過去**: 虚無エネルギーの解析を行っていた天才研究員。「未知への挑戦」として深淵を覗き、呪いを受けた。

## 3. ハクスラ新システム群（育成・拠点強化）
ただ潜るだけでなく、拠点での準備と強化のサイクルに新たな「沼」を用意します。

### ① 『記憶の欠片（メモリー・ビジョン）』システム
ダンジョンのボス討伐や隠し部屋の宝箱から『記憶の欠片』がドロップします。
* **ビジョンの復元**: メニューで消費すると、ソウル・ドライブがかつての仲間たちとの「失われた記憶の1シーン」を復元します。
* **パッシブ強化**: 物語の断片（例「アレスとの誓い」等）を読むごとに、「全キャラの最大HP+5%」や「クリティカル率+2%」といった**永続的なステータスボーナス**が得られます。ストーリーを追うことが最強のビルドに直結します。

### ② 拠点での『自炊バフ（料理）』システム
ダンジョン内でドロップする「魔物の肉」や「地下野菜」を持ち帰り、拠点（酒場・自室）でフライパンを使って自炊します。
* **『地下野菜と魔物肉の炒め物』**: 次の探索中、最大HPが20%増加。
* **『野鳥の肉と卵の煮込み（アビス風親子丼）』**: 次の探索中、一定時間ごとにHPが自動回復。
* **NPC（酒場の女主人）**: 新しいレシピを教えてくれたり、探索のアドバイスをしてくれる先輩肌のキャラクター。

## 4. ストーリー展開タイムライン（全50階層）
50階層という長大なダンジョンを飽きさせないため、階層の進行に合わせてエリアの環境（バイオーム）や物語のフェーズを明確に変化させます。

* **第1〜10階層【古代の石室】（遺跡・浅層）**
  * **雰囲気**: 苔生した崩れた石造りの遺跡。チュートリアルエリア。
  * **敵・ギミック**: スライム系、小型ガーディアン。単純なスイッチ扉や罠。
  * **物語**: 記憶喪失の新人冒険者としてギルドに登録。「アレス」の記憶をアンロックしつつ、ハクスラの基本を学ぶ。
  * **ボス**: 『遺跡の防人 ロスト・ガーディアン』（突進と物理攻撃主体）

* **第11〜20階層【魔導クリスタル鉱脈】（結晶の洞窟・中層）**
  * **雰囲気**: 紫や青に発光する巨大な結晶が壁面を覆い、暗闇を照らす幻想的な洞窟。
  * **敵・ギミック**: ウィンドスライム、エレメンタル、クリスタルゴーレム。触れるとダメージを受ける雷の結晶や、一定時間で消える足場。
  * **物語**: 『記憶の欠片』が集まり始め、自分が「古代の騎士」であること、かつての仲間たちの最期を断片的に思い出す。「リリス」の記憶アンロック。
  * **ボス**: 『結晶竜 クリスタル・ワイバーン』（空を飛び、魔法弾幕を広範囲に撒き散らす）

* **第21〜35階層【深淵の研究所跡】（古代施設・深層）**
  * **雰囲気**: かつての超古代魔法文明が「虚無エネルギー」を研究していた無機質な金属とガラスの施設。赤い警告灯が点滅している。
  * **敵・ギミック**: 暴走したホログラム兵士、キメラ、レーザートラップ、ワープ迷路。また、アビスの真実に近づく主人公を暗殺しにくる「領主の私兵（人間）」が出現。
  * **物語**: 領主ヴァレリウスが真の目的（古代兵器の再起動）のために動いていることが判明。「シアン」の記憶アンロック。
  * **ボス**: 『失敗作：被検体エボリューション』（HPが減るごとに形態変化し、耐性が変わる強敵）

* **第36〜49階層【反逆と突入】（崩壊する防衛網）**
  * **雰囲気**: 領主が古代兵器を起動した影響で空間が崩壊し始めている。溶岩や虚無の淵が広がる危険地帯。
  * **物語**: 都市全体に魔物があふれ出す。酒場の女主人やギルドマスターなど、拠点の人々の協力を得て、兵器の中枢がある最深部へ決死のダイブを敢行する。
  * **ボス**: 『領主直属アサシン・マスター』（分身とステルスを駆使する素早いボス）

* **第50階層【虚無の最下層 - アビス・コア】（最深部）**
  * **雰囲気**: 空間自体が歪み、星空や宇宙のような背景が広がる異空間。
  * **物語**: 古代の暴走した防衛兵器と、領主ヴァレリウスが融合した最終ボスとの決戦。
  * **ボス**: 『領主ヴァレリウス（真の姿）』と『虚無の化身』。レベルを最大まで上げた「かつての仲間たち」のスキルを連続で切り替えながら戦う総力戦。

## 5. アクション・戦闘操作システム
* **移動**: `W`, `A`, `S`, `D` 
* **通常攻撃**: `マウスクリック` または `J` キー（ATK依存・MP消費なし）
* **アクティブスキル**: 職業ごとに4つのスキルが割り当てられる。
  * `I` キー: スキル1（例：ダッシュ回避）
  * `O` キー: スキル2（例：中攻撃・回転斬り）
  * `K` キー: スキル3（例：遠距離魔法）
  * `L` キー: スキル4（例：大技・奥義）
* **インタラクト**: `E` キー（NPC会話、ポータル移動、宝箱開錠）
