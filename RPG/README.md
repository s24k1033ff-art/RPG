# VectorFlow: 次元の流転 (2D Topdown Action RPG)

2D見下ろし平面（XY軸）の物理を極限まで追求した、新感覚の空間ベクトル操作アクションRPG。
プレイヤーは東西南北に吹き荒れる「空間の気流（推進ベクトル）」と「摩擦」を操り、ハザードを滑空して飛び越え、敵を罠に流し込み、古代遺跡の謎を解き明かします。

---

## 📖 世界観とあらすじ

かつて世界は「4つの次元の楔（青の石室、緑の荒野、紫の洞窟、赤の神殿）」によって安定した重力と気流を保っていた。
しかし、深淵より現れた**「虚無の王（ヴォイド・ロード）」**が楔の力を奪い、世界は気流が乱れ奈落が口を開ける崩壊状態（VectorFlow）となってしまった。

記憶を失った次元の騎士（プレイヤー）は、「導きのホログラム」に起こされる。
ホログラムの正体は、楔に封印された次元の女神の残滓だった。
プレイヤーは「ベクトル流転」の力を駆使し、4つのエリアで鍵（女神の欠片）を集め、中央の中庭の奥深くに眠る虚無の王を打ち倒して世界に「重力」を取り戻す旅に出る。

ワークスペース直下にある `preview_demo.html` をブラウザで開くだけで、今すぐ極上の操作感と本格的なRPG要素を体験できます。

👉 **[preview_demo.html を起動](preview_demo.html)**

### ⌨️ キーボード操作
*   **`W` / `A` / `S` / `D`**: 8方向移動（画面絶対座標の直感的移動。移動方向に滑らかに向きが変わります）
*   **`J`**: 次元剣スラッシュ（近接攻撃。敵を「現在の気流の方向」へ強く吹き飛ばす）
*   **`Space`**: グラビティ・ダッシュ（スタミナSPを1消費し、高速ダッシュ。穴の上を飛び越えるホバー手段）
*   **`E`**: インタラクト（会話する、宝箱を開ける、鍵付き扉を開く、ショップ碑石に触れる）
*   **`Shift`**: 摩擦ゼロモード（ホバー）のオン/オフ切替（※最初はロック。ショップでアンロックした後に使用可能）
*   **ベクトル流転 (VFS - 空間の風を操作)**:
    *   **`R`**: 北（上）へ流す
    *   **`F`**: 南（下）へ流す
    *   **`Q`**: 西（左）へ流す
    *   **`E`** (移動していない時): 東（右）へ流す

## 🧭 RPG要素とアドベンチャーループ

1.  **広大な世界とストーリーの導き (Dialogue & Biomes)**
    *   ゲームは「古代の石室」からスタートします。まずは目の前にいる光るNPC（導きのホログラム）に近づき、**`E` キー**で話を聞きましょう。
    *   マップは4画面分の大規模な世界になっており、場所によって「古代の石室」「風吹く荒野」「結晶の洞窟」「忘れられた神殿」と、床や壁の色がシームレスに変化します。
2.  **探索と開錠パズル (Chest & Door)**
    *   宝箱の近くで `E` キーを押して開け、中に眠る【扉の鍵】やゴールドを手に入れましょう。
    *   鍵を持った状態でロックされた扉の前で `E` キーを押すと開錠し、新たなバイオームへ進むことができます。
3.  **戦闘とドロップ回収 (XP & Gold Drops)**
    *   敵を倒すと「ゴールドコイン」と「経験値オーブ」が散らばります。これらはプレイヤーが近づくと**自動的に吸い寄せられて回収**されます！
4.  **レベルアップ (Level Up!)**
    *   経験値（XP）がたまると派手な花火とともにレベルアップ！最大HPと最大VPが永続上昇します。
5.  **古代の強化碑石 (Shop System)**
    *   「古代の強化碑石」に近づいて `E` キーを押すとショップUIが開き、獲得したゴールドで能力を永続強化・アンロックできます。

## 🛠️ 開発・変更履歴 (Changelog)

### [2026-05-25] 超広大シームレスマップ・本格RPG完成版 🗺️✨ (New)
*   **鍵と扉のバイオーム一致システム**: ただの「鍵の数」による管理を廃止し、【青の鍵】【緑の鍵】【紫の鍵】といったエリア固有のID管理システムへ移行。シーケンスブレイク（順序崩壊）を防止し、ストーリー通りの探索導線を実現。
*   **16倍広大なマップ自動結合アルゴリズム**: 3x3の巨大グリッドに各部屋ブロックを動的に合成するアルゴリズムを構築し、これまでの16倍以上に及ぶ「超広大シームレスマップ」を実現！探索の楽しさが爆発的に向上しました。
*   **バイオーム固有のエネミー大増量**: マップ各所にスライム、風のスライム、ガーディアン、クリスタルゴーレム、そして最奥にはボスなどの敵MOBを多数配置し、本格的な戦闘体験ができるようになりました。

### [2026-05-25] 大規模マップ拡張＆ストーリーダイアログ追加 🗺️
*   **キャラクター描画バグの修正**: アイテム回収物理のゼロ除算でCanvasの描画コンテキストが破損しキャラクターが消滅するバグを完全に修正。
*   **巨大なシームレスマップ**: マップデータを4倍（4画面分）に拡張。「古代の石室」「風吹く荒野」「結晶の洞窟」など、エリアごとに壁や床の色彩がシームレスに変化するバイオームシステムを実装。
*   **会話・ダイアログシステム**: NPC（導きのホログラム）に `E` キーで話しかけると、画面下部にリッチなメッセージウィンドウがポップアップし、文字送りができるストーリーシステムを組み込みました。

### [2026-05-25] RPG化アップデート 🚀
*   **通貨＆鍵・宝箱・扉システム**: コイン・経験値のドロップとマグネット回収物理の実装。宝箱とロック扉による探索パズルの追加。
*   **成長とショップシステム**: XPによるレベルアップと、ゴールドを消費して「最大HP」「ホバー（摩擦ゼロ）」などを強化できるガラスモルフィズム風のショップUIを実装。
*   **C#コードの同期**: `PlayerData.cs` や `PlayerController.cs` へのRPGパラメータの完全移植。

### [2026-05-24] 2D見下ろし平面への極限最適化 🌪️
*   **『空間ベクトル流転(VFS)』への移行**: 横スクロール用の「落下重力」を完全廃止し、見下ろし平面の上で東西南北に働く「大気流」と「摩擦ゼロ」を操作するシステムに根本から再設計。
*   **ホバー滑空パズル**: 特定の推進力がある状態でのみ「穴（ピット）」の上を滑空できる画期的なパズル物理を実装。
*   **カメラ向きの0度完全固定**: 3D酔い対策として画面回転を廃止。スプライトのみがVelocity方向に滑らかに回転する王道の2D操作感を実現。
