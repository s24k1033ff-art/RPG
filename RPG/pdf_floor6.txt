Abyss Delver: 迷宮都市の戦記
第6階層：浸食された緑廊 (The Eroded Green Corridor) 完全詳細仕様書 v1.0
1. フロア概要 (Concept & Atmosphere)
第5階層での激しい総力戦を終え、第6階層からはバイオームの雰囲気が「静寂」へとシフトする。施設は地下水
と異常発達した植物に浸食されており、プレイヤーに「高低差（Z軸）」という新たな空間認識の概念を提示す
る。 
ビジュアル: 崩れた石室の隙間から太い根が這い回り、淡く発光する苔（蓄光苔）が自然の照明となっている。
緑と青が混ざったような、静かで美しいアトモスフィア。
レベルデザインの目的: 激しいアクションの直後における「緊張の緩和（ペーシング）」。探索を主体とし、新
たな安全地帯と成長要素へのアクセスを開放する。
2. 新規ギミック：Z軸（高低差）の導入
これまで平面（XY軸）だったマップに、擬似的な「高さ」の概念を取り入れる。 
ギミック名
仕様詳細とプレイヤーのアクション
段差と
落下（崖）
挙動: 高い場所から低い場所へは、そのまま歩いて飛び降りることができる（一方通
行）。しかし、低い場所から高い場所へ直接登ることはできない。
効果: これにより、「上層ルート」と「下層ルート」という立体的な構造が生まれ、
下層から上層へ戻るための迂回路を探す探索の楽しさが生まれる。 
古代のツタ
(Vine Ladder)
見た目: 壁面や段差に群生している太い植物のツタ。
挙動: プレイヤーがツタに重なって「上」または「下」キーを入力すると、昇り降り
のアニメーションに切り替わり、段差を行き来できる。昇降中は無防備になるため、
周囲の敵の排除が必須。 
落下ブロック
挙動: 第2階層のプッシュブロックの応用。上層にあるブロックを下層に突き落とすこ
とで、下層から上層へ登るための「足場（階段代わり）」を作ることができるパズル
要素。 
3. 迷宮内のサンクチュアリ：『静寂の雑貨店』
第6階層の最大の目玉は、魔物が出現しない安全な小部屋に存在する「迷宮内のショップ」の発見である。

🌿 施設：『深淵の万屋 (The Abyss Sundries)』
第6階層の奥深く、淡く光る苔に囲まれた静かな一角に、ひっそりと営業している不思議な雑貨店。店内に
は、地上では見かけない珍しい素材や、過去の探索者たちが残した遺物が整然と陳列されている。
NPC: 店番の女性「エルザ」
物静かだが芯の強い、先輩探索者のような落ち着いた雰囲気を持つ女性。かつては優秀な冒険者だったが、
ある理由で一線を退き、現在はアビスの中でこの店を切り盛りしている。彼女はプレイヤーに、的確なプロ
のアドバイスと、ダンジョン探索の効率化（シフト管理）を支援してくれる。 
雑貨店の提供機能
現地調達・売却: 探索中にインベントリが溢れた際、拠点に戻らずに素材を売却したり、緊急用の回復薬（ポー
ション）を補充できる。
限定レシピの販売: 地上の「Memories' Cafe」では手に入らない、特殊なバフ効果を持つ自炊レシピを購入で
きる。
探索シフト（ミニクエスト）: エルザから「次の階層で特定の魔物を10匹討伐して」といった、1回の探索サイ
クル（シフト）内でこなすサブクエストを受注でき、達成すると特別な報酬がもらえる。
4. 浸食された環境のエネミー (Enemy Variations)
植物と融合した魔物たちが登場し、地形を利用した厄介な行動をとる。 
モス・スライム (Moss Slime): 緑色の苔に覆われたスライム。床が「苔タイル」になっている場所の上にいる
と、毎秒HPが自動回復する。倒すには、苔のない場所へ誘い出すか、回復量を上回る瞬間火力が必要。
ソーン・アーチャー (Thorn Archer): トゲ付きのツルをまとったスケルトン。放ってくる矢に当たると、ダメー
ジに加えて「1秒間、移動入力が完全にロックされる（バインド状態）」となる。段差を登る最中に狙撃される
と致命傷になり得る。

これまでの平坦なマップから、Z軸を意識させる立体的（メトロイドヴァニア的）な構造へ。

6. プログラマー向け実装データ構造 (Implementation Notes)
Z軸（高さ）の概念を2DトップダウンのTileMapで表現するための実装方針。 
⚠️ 実装上の注意点（疑似Z軸）
2DゲームにおいてZ軸を実装する場合、y 座標（画面の上下）と z 座標（高さ）の混同に注意。段差（cliff）
の判定は、プレイヤーの current_elevation（現在の高さレイヤー値）変数を持たせ、下層(elevation=0)
にいる時は cliff を完全な壁（Solid）として扱い、上層(elevation=1)にいる時は床として扱うロジックを組む
こと。

  "floor_id": "abyss_f6",

      "collision": true

      "name": "cliff_layer", /* 段差の表現 */
      "z_index": 1,
      "collision_type": "one_way", /* 上からは降りれる、下からは壁 */
      "direction": "down"
    },
    {
      "name": "vine_layer", /* ツタの表現 */
      "z_index": 2,
      "interaction": "climbable"
    }
